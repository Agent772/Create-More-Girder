## Version 2.3.0

### Added
- Added walk-on beam collision for girder struts. Connected struts now generate solid collision along the full span so players and mobs can stand on them. Powered by the **Strut Your Stuff** library (`com.cake.struts:struts:1.1.0+mc1.20.1`), which is now a **required dependency** — Forge will display a clear missing-dependency screen if it is not installed alongside Create: More Girder.
